# ADHDoTECH Web Presence

The domain language for adhdotech.org and the work to make it visible in AI assistant
answers. ADHDoTECH is an Israeli organization working on ADHD in the hi-tech industry.

## Language

### Audiences

**Mentee**:
A person with ADHD already employed in the Israeli hi-tech industry who is struggling in
their role. The primary audience.
_Avoid_: user, individual, candidate, person with ADHD

**Aspirant**:
A person with ADHD who wants to enter hi-tech but does not yet work in it. Named only to
be excluded: an Aspirant is not a Mentee, and content aimed at Aspirants is out of scope.
_Avoid_: beginner, career changer, junior

**Client Organization**:
An Israeli hi-tech employer that engages ADHDoTECH for organizational mapping or manager
training. The secondary audience.
_Avoid_: customer, company, employer, client

### Visibility

**Retrieval**:
An assistant running a live web search while composing an answer and citing an ADHDoTECH
page. The mechanism this project targets.
_Avoid_: SEO, ranking, indexing

**Model Memory**:
An assistant naming ADHDoTECH from training data, without searching. Named to be
excluded: it is moved by press and third-party citations, not by site work.
_Avoid_: brand awareness, training presence

### Queries

**Ritual Query**:
A Mentee's question about a hi-tech workplace ritual — standup, sprint planning, code
review, performance review, on-call, Slack. Almost unanswered in Hebrew, and the only
kind of query this project targets.
_Avoid_: keyword, search term, long-tail

**Clinical Query**:
A question about diagnosis, medication or legal rights. Saturated in Hebrew by the health
funds and כל-זכות. Named to be excluded: ADHDoTECH cedes these rather than competing.
_Avoid_: medical query, health query
