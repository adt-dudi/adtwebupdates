# AI Retrieval Baseline — September 2026

Recorded **before** any change to adhdotech.org. Once the site changes, this "before"
cannot be recreated, so it was filled in first.

## How it was run

Each query was asked verbatim in **ChatGPT**, **Gemini**, and **Perplexity**, via Chrome browser
automation, in a fresh chat per query (to avoid conversation-level context bleed between
queries within the same assistant).

**Deviation from the original instructions:** the template calls for a logged-out or temporary
session "so your own history doesn't inflate the result." Per explicit instruction from the
person running this check, all three assistants were used **logged in as the account owner**
instead. See the Notes section for why this matters and how it likely affected the results.

Code used per cell:

| Code | Meaning |
|------|---------|
| `—` | ADHDoTECH not mentioned at all |
| `M` | Mentioned by name, no link |
| `L` | Cited with a working link to adhdotech.org |
| `N/T` | Not tested (see Notes) |

Assistants are non-deterministic — the same question can return different sources on a
re-run. Treat the totals as directional, not as a measurement.

## Notes

- **Date run:** September 21, 2026.
- **Logged out / fresh session:** No. Per explicit instruction, all three assistants were
  used while logged into the account owner's own accounts, not a logged-out or temporary
  session as the original template suggested. Each individual query was still asked in a
  brand-new chat (not a continued conversation), to avoid *within-session* context bleed
  between the 7 queries per assistant per language — but each account's broader history,
  personalization, and memory were active throughout.
- **Anything surprising:**
  - The Gemini account used is not a neutral personal account — it's a **Google Workspace
    account belonging to ADHDoTech itself**, with a chat history full of ADHDoTech-specific
    prior conversations (fundraising strategy, partnership due diligence, board governance,
    donor campaigns, etc.), plus notebooks explicitly named for ADHDoTech material. This is
    about as favorable a "home-field" condition as an AI retrieval baseline could have — if
    anything was going to surface ADHDoTECH by name from account context alone, it was this.
    It didn't: Gemini returned `—` on all 14 Hebrew + English queries.
  - Despite that account bias *and* querying from the founder's own logged-in, personalized
    accounts across all three assistants, **ADHDoTECH did not appear once** in any of the 39
    tested checks (0 `M`, 0 `L`). If anything, using logged-in/personalized accounts should
    have inflated the result in ADHDoTECH's favor relative to a clean session — and it still
    came up empty. That makes the "before" baseline, if anything, a generous one for
    ADHDoTECH going into any future change to the site.
  - ChatGPT and Gemini answered almost every query from their own internal knowledge with
    **no citations at all** — only Perplexity cites by default, and ChatGPT triggered a live
    web search on 2 of 14 queries (Hebrew Q7 and English Q6–7, all Israel/legal-flavored
    questions where it apparently judged a search necessary).
  - **Perplexity's free-tier search limit was hit** partway through English query 5 ("You've
    reached your free search limit... resets in a few hours"), so Perplexity results for
    English queries 5, 6, and 7 are marked `N/T` (not tested) rather than `—`. Everything else
    in this report (all 21 Hebrew checks, all 21 English ChatGPT/Gemini checks, and the first
    4 of 7 English Perplexity checks) completed normally. Happy to run those last 3 Perplexity
    checks once the quota resets, or on a Perplexity Pro account, if you want full 42/42
    coverage — just say the word.
